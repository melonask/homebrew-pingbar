# homebrew-pingbar

Homebrew tap for [PingBar](https://github.com/melonask/PingBar), a lightweight macOS menu-bar monitor for HTTP availability and latency.

## Install

```sh
brew install --cask melonask/pingbar/pingbar
```

Homebrew adds the tap automatically, so `brew tap melonask/pingbar` is optional.

## Update

```sh
brew upgrade --cask pingbar
```

## Uninstall

```sh
brew uninstall --cask pingbar
brew untap melonask/pingbar
```

## Maintenance

`Casks/pingbar.rb` is generated by `scripts/update-cask.sh` in the [PingBar repository](https://github.com/melonask/PingBar). After publishing a new release:

```sh
./scripts/update-cask.sh        # rewrites Casks/pingbar.rb from the latest release
cp Casks/pingbar.rb ../homebrew-pingbar/Casks/pingbar.rb
```
